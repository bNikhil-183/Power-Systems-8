6. Three-Phase Fault (Using Current Impedance Matrix)

Fault Current = Prefault Voltage / (Diagonal Impedance + Fault Impedance) • Voltage at bus i = Prefault Voltage − Transfer Impedance × Fault Current • Branch currents use the branch list defined in section 4. Prefault currents are assumed zero.
